Баланс · ближе всех к Slack

Mattermost

Самая зрелая платформа плагинов (плагин — дополнение, которое встраивается в чат и добавляет кнопки, панели, формы) среди self-hosted систем. Умеет показывать правую панель с интерфейсом приложения, модальные формы (всплывающие окна с полями для ввода), свои типы сообщений, слэш-команды (команды через «/», как /remind в Slack) и маркетплейс готовых дополнений. Ставится одним docker compose (один файл с описанием и одна команда — всё поднимается само) на 2 ГБ оперативной памяти.

  • Берите Team Edition — полностью открытую версию под лицензией MIT (пользуйтесь как хотите, никаких обязательств) до 250 пользователей, но без SSO (единого входа через корпоративный аккаунт Google, Microsoft и т. п.). Либо Entry — бесплатный режим платной версии со всеми функциями, который показывает только последние 10 000 сообщений (старые остаются в базе, но их не видно и не найти поиском).
  • Минус: нет E2EE (сквозного шифрования: когда прочитать сообщение может только получатель, а сервер хранит нечитаемый набор байт; здесь сервер видит текст), и push-уведомления на телефоны (всплывающие оповещения, когда приложение закрыто) в рабочем режиме — только за деньги или со своей сборкой мобильных приложений.

Безопасность · виджеты как мини-аппы

Element + Matrix (ESS Community)

E2EE включено по умолчанию (сквозное шифрование: текст шифруется на устройстве отправителя и расшифровывается только у получателей, сервер и его администратор переписку не читают). Виджеты — это любая веб-страница, встроенная прямо в комнату чата, то есть ближайший аналог мини-приложений Telegram. Мосты (боты-переводчики между мессенджерами) соединяют с Telegram, WhatsApp, Slack и Discord через проект mautrix.

  • Плюс: всё под AGPLv3 (свободная лицензия: пользуйтесь и меняйте бесплатно; единственное условие — если переделаете код и будете предоставлять его как сервис другим, изменения надо опубликовать; для своей команды обязательств нет), без лимитов по пользователям (нет счётчиков вроде «до 50 человек» или «10 000 сообщений»); push на телефон идёт через шлюз matrix.org (сервер-посредник, который передаёт уведомления Apple и Google) бесплатно и с любого вашего сервера.
  • Минус: официальная установка — Kubernetes (система для управления множеством контейнеров, обычно для крупной инфраструктуры; k3s — её облегчённая версия для одной машины) плюс Helm (установщик пакетов для Kubernetes), а не простой docker compose. E2EE ломает серверный поиск: сервер не может искать по тексту, которого не видит, поэтому поиск по зашифрованным комнатам работает только в десктопном Element по сообщениям, скачанным на этот компьютер, а в браузере и на телефоне — нет.

Проще всего · честно бесплатно

Zulip

Лицензия Apache 2.0 (свободная, без обязательств, как MIT), все функции сервера бесплатны — включая SAML, LDAP и SCIM (способы подключить корпоративный вход и автоматически подтягивать список сотрудников из Active Directory, Google Workspace или Okta; настраиваете сами). Один установочный скрипт, 130+ интеграций (готовых подключений: GitHub, Jira, системы мониторинга, календари) и Slack-совместимые вебхуки (вебхук — адрес, на который внешний сервис присылает сообщение; здесь формат тот же, что у Slack, старые интеграции переезжают без переделки). Быстрые и прозрачные security-релизы (обновления, закрывающие уязвимости, с подробным описанием).

  • Минус: встроенного веб-интерфейса и модалок нет (приложение не может нарисовать форму или окно внутри чата), только боты и вебхуки; мобильные push бесплатны лишь до 10 пользователей.
  • Нюанс: модель «канал + тема» (внутри канала у каждого обсуждения есть заголовок, как на форуме) требует привычки, хотя с версии 11.0 темы можно отключить.

Антирекомендация на 2026 год

Rocket.Chat

Платформа приложений отличная: приложения на TypeScript (язык программирования для веб-интерфейсов) умеют показывать модальные окна, боковую панель и кнопки, есть маркетплейс. Но год выдался плохим: критический обход аутентификации (ошибка в одном слове кода, из-за которой проверка пароля всегда отвечала «верно» — зайти можно было в любой аккаунт с любым паролем), плюс ещё четыре серьёзных CVE (CVE — официальный номер уязвимости в международной базе) за полгода.

  • Заморочки: обязательная регистрация workspace (вашего экземпляра чата) в облаке Rocket.Chat, иначе не работают push и маркетплейс; в Community (открытой бесплатной версии) только 5 включённых приложений и ни одного своего.
  • Инфраструктура: база данных MongoDB 8 с реплика-сетом из трёх копий (три экземпляра базы, которые дублируют друг друга ради надёжности — три процесса вместо одного); план Pro снят с продажи 29.04.2026.

Что считать «мини-аппками» в чате

У Slack это Block Kit: модальные окна, интерактивные сообщения с кнопками, вкладка приложения. У Telegram — Mini Apps: полноценная веб-страница, открытая внутри чата. Среди self-hosted систем встречаются три уровня.

A

Веб-приложение внутри комнаты

Произвольный адрес открывается в sandbox-iframe (изолированное окно внутри страницы, как встроенное видео с YouTube) прямо в чате и общается с клиентом через postMessage (безопасный канал обмена сообщениями между окном и страницей). Самый близкий аналог Telegram Mini Apps.

Есть: Matrix-виджеты в Element (matrix-widget-api). Корневые компоненты webapp-плагинов Mattermost (плагин может нарисовать целый свой экран) — частично.

B

Модалки, панели и формы от приложений

Приложение описывает интерфейс из готовых блоков (кнопки, поля ввода, списки), а рисует их сам чат-клиент: всплывающие диалоги, боковые панели, кнопки в сообщениях, слэш-команды. Это модель Slack Block Kit.

Есть: Mattermost (плагины, interactive dialogs — всплывающие формы), Rocket.Chat (Apps-Engine, UI Kit: модальное окно, боковая панель, кнопки действий).

C

Только боты и вебхуки

Интеграция присылает текст, реакции и вложения, отвечает на команды, но интерфейса внутри чата не создаёт. Бот — это программа, которая выступает участником чата; вебхук — адрес, на который внешний сервис шлёт уведомления.

Есть: Zulip (130+ интеграций, интерактивные боты), Nextcloud Talk (боты: текст и реакции), Campfire (боты по HTTP), Stoat (Bot API).

Плюс слэш-команды (команды через «/»), вебхуки (адреса для входящих сообщений от внешних сервисов), OAuth2-приложения (внешние сервисы, которым пользователь разрешает действовать от своего имени) и маркетплейс: Jira, GitHub, GitLab, Zoom, звонки, Playbooks (пошаговые сценарии для инцидентов и релизов), Agents (ИИ-помощники).
  • Редакции после v11. Team Edition остаётся: лицензия MIT (полностью свободная), до 250 активированных пользователей, SSO (единый вход через корпоративный аккаунт, включая GitLab) убрано. Entry — бесплатный режим платной Enterprise Edition «со всеми функциями Enterprise Advanced», но история ограничена 10 000 сообщений (старые остаются в базе, но не видны и не ищутся), без compliance (экспорта переписки для проверяющих, юридического удержания, правил хранения) и HA (high availability: запуск нескольких копий сервера, чтобы он не падал при сбое одной). Лимиты на push, звонки, Boards (доски задач), Playbooks и ИИ помечены «вступят в силу в будущем релизе».
  • Безопасность. E2EE (сквозное шифрование, при котором сервер не видит текст) официально не поддерживается: есть только TLS в транзите (шифрование канала между приложением и сервером, как https у сайтов) и дисковое шифрование; в базе данных сообщения лежат открытым текстом, чтобы работали поиск и compliance. Есть сторонний плагин E2EE от Quarkslab. Bugcrowd (программа вознаграждений за найденные уязвимости), ежемесячные релизы, ESR (extended support release — версия с длительной поддержкой, куда месяцами приходят только исправления). 2026: DoS через WebSocket без аутентификации (DoS — атака, которая «роняет» сервер; здесь любой без входа мог отправить особое сообщение и остановить его, CVE-2026-5740), обход прав в Playbooks (CVE-2026-6343), кража кода входа через мобильное приложение при подключении к подставному серверу (CVE-2026-22880); 2025 — критичные дыры в Boards.
  • Push. Push-уведомления (всплывающие оповещения на телефоне, когда приложение закрыто) ваш сервер не может отправить напрямую: Apple и Google принимают их только от того, кто опубликовал приложение в сторе. Поэтому они идут через сервер Mattermost: бесплатный TPNS — «тестовый», без гарантий и «не рекомендуется в проде»; HPNS — надёжный, но только по подписке. Альтернатива — свой push-сервер и своя сборка мобильных приложений под своим именем в сторах.
  • Цены. Официальная страница цен отдаёт цифры только скриптом; по сторонним обзорам Professional стоит около $10 за пользователя в месяц при годовой оплате. Профессиональная редакция рассчитана на команды до 250 человек и включает SAML/LDAP/OIDC (три стандарта корпоративного входа) и гостевой доступ.

Вердикт: самый «слаковый» из всех, с лучшей платформой форм и панелей. Для небольшой команды без SSO — Team Edition; если нужны Playbooks, Boards и аудит — Entry, но следите за потолком истории.

Подводные камни, о которых молчат лендинги

Шесть вещей, которые всплывают через месяц после установки.

1Push-уведомления — главная ловушка self-hostApple и Google принимают уведомления только от того, кто опубликовал приложение в сторе, поэтому ваш сервер шлёт их через шлюз вендора (его сервер-посредник): у Mattermost бесплатный только тестовый, у Rocket.Chat лимит 10 000 в месяц в Community, у Zulip бесплатно до 10 пользователей, у Nextcloud прокси закрытый. Честнее всех Matrix: шлюз matrix.org бесплатен для любого сервера.
2Бесплатные редакции переписываютMattermost в v11 ввёл потолок истории в Entry и урезал Team Edition до 250 пользователей без SSO. Rocket.Chat в 6.5–7.0 перевёл свои приложения в премиум и ввёл регистрацию workspace. Фиксируйте версию (не ставьте «latest» автоматически) и читайте форум перед мажорным обновлением.
3E2EE ломает поиск и ботовСквозное шифрование означает, что сервер хранит нечитаемые байты. В Element и Rocket.Chat такие комнаты не индексируются сервером (он не может построить поисковый указатель по тексту, которого не видит), а ботам нужны ключи. Для рабочего чата с интеграциями чаще выбирают шифрование только «до сервера» плюс шифрование диска, как у Mattermost и Zulip, и честно это понимают.
4Переходы мобильных клиентовElement Classic уходит из сторов 31.12.2026, вместо него Element X. Zulip с июня 2025 перешёл на Flutter-приложение. У Stoat iOS ещё в разработке. Проверяйте, что нужные функции уже есть в новом клиенте.
5AGPL и MIT — не одно и то жеAGPLv3 — свободная лицензия с условием: если вы меняете код и предоставляете его как сервис другим, изменения нужно опубликовать; для своей команды без модификаций обязательств нет. Под ней — Synapse, проект Mattermost, Stoat, Twake и Wire. MIT и Apache 2.0 — свободные лицензии без таких условий: Team Edition Mattermost, Community Rocket.Chat и Campfire — MIT, Zulip — Apache 2.0.
6База данных — часть выбораMattermost, Zulip и Synapse живут на PostgreSQL (классическая база с таблицами). Rocket.Chat и Stoat требуют MongoDB (документная база другого типа), причём Rocket.Chat 8.x — именно 8.0 с реплика-сетом (тремя копиями). Один бэкап-скрипт на всё не получится.

Минимальные пути для финалистов по официальным инструкциям. Домены, сертификаты и бэкапы — по ссылкам из каждой карточки.

Mattermost · docker compose

Официальный репозиторий mattermost/docker: скачать, заполнить файл .env (настройки: домен, версия), поднять с nginx (веб-сервером, который принимает https и передаёт запросы приложению) или без. Минимум 2 ГБ RAM на хост.

# по гайду Deploy Mattermost via Docker
git clone https://github.com/mattermost/docker
cd docker && cp env.example .env
# в .env: DOMAIN=chat.example.com, MATTERMOST_IMAGE_TAG
mkdir -p ./volumes/app/mattermost/{config,data,logs,plugins,client/plugins,bleve-indexes}
sudo chown -R 2000:2000 ./volumes/app/mattermost
sudo docker compose -f docker-compose.yml -f docker-compose.nginx.yml up -d

Team Edition — образ mattermost-team-edition; Entry — обычный образ Enterprise без лицензии.

Отсеяны и почему

Популярные «альтернативы Slack», которые не проходят по условию self-host или не подходят под рабочее пространство.

Pumble, Zoho Cliq, Ryver — облачные сервисы (работают только на серверах вендора); официального on-premise предложения (установки на свой сервер) не найдено. Zoho предлагает on-prem только для Analytics и Creator.
Chanty, Flock — self-host упоминается лишь в сторонних сравнениях с противоречивыми цифрами; на официальных сайтах подтверждения нет. Не считаем.
Spacebar (ex-Fosscord) — Discord-совместимый сервер (к нему подходят клиенты и боты Discord), активно развивается (коммиты сентября 2026), но это реплика Discord для сообществ, а не рабочий чат с платформой приложений.
Tinode — сервер мессенджера на Go, релизы в 2026 году есть, но авторы сами называют его beta-quality; это конструктор мессенджера для разработчиков, а не готовая замена Slack.
SimpleX Chat — защищённый мессенджер с self-hosted релеями (серверами-посредниками), но без рабочих пространств с каналами и платформы приложений в смысле Slack.
Mattermost Apps Framework — упомянут отдельно, потому что по нему ещё много статей: объявлен устаревшим в v10, перестал работать в v11. Новые интеграции — только плагины, вебхуки и слэш-команды.

Словарь

Термины со страницы простым языком, по алфавиту латиницей, потом кириллицей.

AGPLv3, MIT, Apache 2.0, source-availableЛицензии на код. MIT и Apache 2.0 — свободные без условий: ставьте, меняйте, продавайте. AGPLv3 — свободная с условием: если изменили код и предоставляете его как сервис другим, изменения надо опубликовать; для своей команды без модификаций ничего делать не нужно. Source-available — код виден, но пользоваться им без платной лицензии нельзя.
AnsibleИнструмент автоматической настройки серверов: вы описываете «что должно стоять», он сам всё ставит и настраивает по SSH.
CVE и CVSSCVE — официальный номер уязвимости в международной базе (например, CVE-2026-28514). CVSS — оценка её опасности от 0 до 10; 9 и выше — критическая.
Docker, docker composeDocker запускает программы в контейнерах — изолированных «коробках» со всем нужным внутри. docker compose — файл, где описано несколько контейнеров сразу (чат, база, веб-сервер), и одна команда, которая всё это поднимает.
DoSDenial of Service — атака, цель которой не украсть данные, а «уронить» или замедлить сервер, чтобы им не могли пользоваться другие.
E2EEEnd-to-end encryption, сквозное шифрование: сообщение шифруется на устройстве отправителя и расшифровывается только у получателей. Сервер и его администратор видят лишь нечитаемые байты. Обратная сторона: сервер не может искать по тексту, а ботам нужны ключи.
Federation (федерация)Умение сервера переписываться с чужими серверами того же протокола, как почта между доменами. В Matrix есть, её можно выключить и жить «закрытым» сервером.
HA, complianceHA (high availability) — запуск нескольких копий сервера, чтобы при сбое одной остальные продолжали работать. Compliance — функции для проверяющих: экспорт переписки, юридическое удержание, правила хранения.
HPB, SFU, signalingУ Nextcloud Talk: High Performance Backend — отдельный сервер для звонков. Signaling координирует соединения, SFU принимает видеопоток от каждого участника и раздаёт остальным, иначе каждый шлёт видео каждому и всё встаёт после 4–5 человек.
iframe, sandbox, postMessageiframe — окно одной веб-страницы внутри другой (так встраивают видео YouTube). Sandbox — режим, в котором это окно изолировано и не может лезть в основную страницу. postMessage — безопасный способ обмена сообщениями между ними.
Kubernetes, k3s, HelmKubernetes — система управления множеством контейнеров на многих машинах, стандарт для крупной инфраструктуры. k3s — его облегчённая версия, которая ставится на одну машину одной командой. Helm — установщик пакетов (чартов) для Kubernetes.
LTS, ESR, EOLLTS и ESR — версии с длительной поддержкой: месяцами получают только исправления, без новых функций. EOL — дата, после которой версия больше не обновляется, в том числе по безопасности.
MLS, Olm, MegolmПротоколы шифрования. Olm и Megolm — то, чем шифрует Matrix (личные и групповые чаты). MLS — новый стандарт группового шифрования от IETF (организации интернет-стандартов), на нём работает Wire.
OAuth, OIDCСпособ дать внешнему сервису доступ к вашему аккаунту без передачи пароля («войти через Google»). OIDC (OpenID Connect) — надстройка над OAuth именно для входа.
PostgreSQL, MongoDB, реплика-сетБазы данных. PostgreSQL — классическая с таблицами, MongoDB — документная (хранит записи как JSON). Реплика-сет — несколько копий MongoDB, дублирующих друг друга ради надёжности; Rocket.Chat рекомендует три.
Push-уведомления и шлюзОповещения на телефоне, когда приложение закрыто. Apple и Google принимают их только от издателя приложения, поэтому ваш сервер отдаёт их на шлюз вендора (сервер-посредник), а тот — в Apple/Google. У каждого вендора свои лимиты и цены на этот шлюз.
REST API, вебхук, слэш-командаREST API — программный интерфейс, через который другие программы читают и пишут в чат по HTTP. Вебхук — адрес, на который внешний сервис присылает уведомление (например, GitHub о новом коммите). Слэш-команда — команда через «/» в поле ввода, как /remind в Slack.
Self-hosted, on-premiseПрограмма работает на вашем сервере (своём железе или арендованной виртуалке), а не в облаке вендора. Данные остаются у вас, обновления и бэкапы — тоже на вас.
SSO, SAML, LDAP, SCIMSSO — единый вход через корпоративный аккаунт (Google Workspace, Microsoft, Okta). SAML и OIDC — стандарты такого входа. LDAP/Active Directory — каталог сотрудников, из которого можно брать пользователей. SCIM — автоматическая синхронизация этого списка (уволили — доступ исчез).
TLSШифрование канала между приложением и сервером, то же, что https у сайтов. Защищает от прослушки по дороге, но сервер текст видит.
UnifiedPushОткрытый стандарт доставки push-уведомлений на Android без Google: вы ставите приложение-распределитель (ntfy, NextPush) и свой сервер.
Workspace, Team Edition, Entry, Community, StarterWorkspace — ваш экземпляр чата. Остальное — названия редакций у вендоров: у Mattermost Team Edition (открытая) и Entry (бесплатный режим платной), у Rocket.Chat Community (открытая) и Starter (бесплатный план с регистрацией).
Бот, мостБот — программа, которая участвует в чате как пользователь: отвечает, присылает отчёты. Мост (bridge) — бот-переводчик между мессенджерами: сообщение из Telegram появляется в Matrix и наоборот.
Виджет, модалка, contextual barВиджет — веб-страница, встроенная в комнату чата. Модалка — всплывающее окно с полями и кнопками поверх чата. Contextual bar — боковая панель, которая выезжает справа с информацией или формой.
Плагин, Apps-Engine, маркетплейсПлагин/приложение — дополнение, которое встраивается в чат и добавляет функции. Apps-Engine — механизм Rocket.Chat для запуска таких приложений внутри сервера. Маркетплейс — каталог готовых дополнений с установкой в один клик.
Инъекция (SQL/NoSQL)Атака, при которой в поле ввода (логин, поиск) подставляют команды для базы данных, и сервер их выполняет. Позволяет обойти вход или вытащить чужие данные.
