Коротко: три финалиста и одна антирекомендация

Если нужен один ответ — Mattermost. Если безопасность важнее удобства установки — Element на Matrix. Если хочется поставить за полчаса и забыть — Zulip.

Баланс · ближе всех к Slack

Mattermost

Самая зрелая платформа плагинов среди self-hosted: правая панель, модальные формы, кастомные типы сообщений, слэш-команды, маркетплейс. Ставится одним docker compose на 2 ГБ RAM.

  • Берите Team Edition (MIT) до 250 пользователей без SSO, либо Entry — бесплатный режим Enterprise со всеми функциями, но с потолком истории в 10 000 сообщений.
  • Минус: нет E2EE и push в проде только через платный HPNS или свою сборку приложений.

Безопасность · виджеты как мини-аппы

Element + Matrix (ESS Community)

E2EE включено по умолчанию, виджеты — это любой веб-URL в iframe внутри комнаты, что ближе всего к Telegram Mini Apps. Мосты в Telegram, WhatsApp, Slack и Discord через mautrix.

  • Плюс: всё под AGPLv3, без лимитов по пользователям; push через шлюз matrix.org бесплатно.
  • Минус: официальная установка — Kubernetes (k3s) + Helm, а не compose; E2EE ломает серверный поиск.

Проще всего · честно бесплатно

Zulip

Apache 2.0, все функции сервера бесплатны (SAML, LDAP, SCIM настраиваете сами). Один установочный скрипт, 130+ интеграций и Slack-совместимые вебхуки. Быстрые и прозрачные security-релизы.

  • Минус: встроенного веб-UI и модалок нет, только боты и вебхуки; мобильные push бесплатны лишь до 10 пользователей.
  • Нюанс: модель «канал + тема» требует привычки, хотя с 11.0 темы можно отключить.

Антирекомендация на 2026 год

Rocket.Chat

Платформа приложений отличная (TypeScript-приложения, модалки, contextual bar, маркетплейс), но год выдался плохим: критический обход аутентификации, когда любой пароль подходил к любому аккаунту, плюс ещё четыре серьёзных CVE за полгода.

  • Заморочки: обязательная регистрация workspace в облаке Rocket.Chat, иначе нет push и маркетплейса; в Community только 5 включённых приложений и ни одного приватного.
  • Инфраструктура: MongoDB 8 с реплика-сетом из трёх членов, план Pro снят с продажи 29.04.2026.

Что считать «мини-аппками» в чате

У Slack это Block Kit: модальные окна, интерактивные сообщения, вкладка приложения. У Telegram — Mini Apps: полноценная веб-страница внутри чата. Среди self-hosted систем встречаются три уровня.

A

Веб-приложение внутри комнаты

Произвольный URL открывается в sandbox-iframe прямо в чате и общается с клиентом через postMessage. Самый близкий аналог Telegram Mini Apps.

Есть: Matrix-виджеты в Element (matrix-widget-api). Корневые компоненты webapp-плагинов Mattermost — частично.

B

Модалки, панели и формы от приложений

Приложение рисует UI из блоков, которые рендерит сам клиент: диалоги, боковые панели, кнопки в сообщениях, слэш-команды. Это модель Slack Block Kit.

Есть: Mattermost (плагины, interactive dialogs), Rocket.Chat (Apps-Engine, UI Kit: modal, contextual bar, action buttons).

C

Только боты и вебхуки

Интеграция присылает текст, реакции, вложения и реагирует на команды, но интерфейса внутри чата не создаёт.

Есть: Zulip (130+ интеграций, interactive bots), Nextcloud Talk (боты: текст и реакции), Campfire (HTTP-боты), Stoat (Bot API).

  • Безопасность. E2EE официально не поддерживается: только TLS в транзите и дисковое шифрование, в БД сообщения открыты ради поиска и compliance. Есть сторонний плагин E2EE от Quarkslab. Bugcrowd, ежемесячные релизы, ESR. 2026: DoS через WebSocket без аутентификации (CVE-2026-5740), обход прав в Playbooks (CVE-2026-6343), кража SSO-кода через мобильное приложение (CVE-2026-22880); 2025 — критичные дыры в Boards.
  • Push. Бесплатный TPNS не имеет SLA и «не рекомендуется в проде»; HPNS — только по подписке. Альтернатива — свой push-proxy и своя сборка мобильных приложений.
  • Цены. Официальная страница цен отдаёт цифры только скриптом; по сторонним обзорам Professional стоит около $10 за пользователя в месяц при годовой оплате. Профессиональная редакция рассчитана на команды до 250 человек и включает SAML/LDAP/OIDC и гостевой доступ.

Вердикт: самый «слаковый» из всех, с лучшей платформой форм и панелей. Для небольшой команды без SSO — Team Edition; если нужны Playbooks, Boards и аудит — Entry, но следите за потолком истории.

  • Звонки. Без High Performance Backend — peer-to-peer и E2EE, но практический предел 3–5 участников. HPB (signaling, SFU) тянет 30–50+ активных, но это отдельная инсталляция.
  • Push. Сервер обязан достигать push-notifications.nextcloud.com; прокси закрытый, свой поднять нельзя. Для Android есть UnifiedPush.
  • Новое в 2026. Hub 26 Summer добавил каналы, объявления и «классифицированные» беседы с запретом пересылки и публичных ссылок.

Вердикт: отличный бонус к уже стоящему Nextcloud, но не самостоятельный аналог Slack с приложениями.

Остальные: Twake Chat, Tchap, Wire, Threema OnPrem

Проверены и отложены: либо слишком тяжёлые, либо не являются рабочим пространством

  • Twake Chat (Linagora, AGPL-3.0, 2.25.2 от 06.10.2026) — Flutter-клиент Matrix со своим ToM-сервером; self-host означает Synapse + ToM + identity + LDAP. Проще взять Element.
  • Tchap — мессенджер французского госсектора на Matrix, 92 открытых репозитория, веб-клиент — мягкий форк Element Web. Код открыт, но это дистрибутив под конкретного заказчика, а не продукт для сторонних команд.
  • Wire — AGPL, шифрование MLS, но прод-установка через wire-server-deploy это Kubernetes и кластер Cassandra, по обзорам около 16 виртуальных машин. Поддерживаемый on-prem — по контракту.
  • Threema OnPrem — проприетарный швейцарский мессенджер с E2EE; цена по запросу, сторонние оценки — установка около CHF 3 800 и около CHF 11,90 за пользователя в год при минимуме порядка 150 человек. Тредов и приложений нет.

Вердикт: ни один не закрывает запрос целиком.

Подводные камни, о которых молчат лендинги

Шесть вещей, которые всплывают через месяц после установки.

1Push-уведомления — главная ловушка self-hostПриложения в сторах подписаны ключом вендора, поэтому push почти всегда идёт через его шлюз: у Mattermost бесплатный только тестовый, у Rocket.Chat лимит 10 000 в месяц в Community, у Zulip бесплатно до 10 пользователей, у Nextcloud прокси закрытый. Честнее всех Matrix: шлюз matrix.org бесплатен для любого homeserver.
2Бесплатные редакции переписываютMattermost в v11 ввёл потолок истории в Entry и урезал Team Edition до 250 пользователей без SSO. Rocket.Chat в 6.5–7.0 перевёл приватные приложения в премиум и ввёл регистрацию workspace. Фиксируйте версию и читайте форум перед мажорным обновлением.
3E2EE ломает поиск и ботовВ Element и Rocket.Chat зашифрованные комнаты не индексируются сервером, а ботам нужны ключи. Для рабочего чата с интеграциями чаще выбирают шифрование «до сервера» плюс дисковое, как у Mattermost и Zulip, и честно это понимают.
4Переходы мобильных клиентовElement Classic уходит из сторов 31.12.2026, вместо него Element X. Zulip с июня 2025 перешёл на Flutter-приложение. У Stoat iOS ещё в разработке. Проверяйте, что нужные функции уже есть в новом клиенте.
5AGPL и MIT — не одно и то жеSynapse, Mattermost (проект), Stoat, Twake и Wire — под AGPLv3: модификации при предоставлении сервиса нужно открывать. Team Edition Mattermost, Community Rocket.Chat и Campfire — MIT, Zulip — Apache 2.0.
6База данных — часть выбораMattermost и Zulip живут на PostgreSQL, Synapse тоже. Rocket.Chat и Stoat требуют MongoDB, причём Rocket.Chat 8.x — именно 8.0 с реплика-сетом. Один бэкап-скрипт на всё не получится.

Поставить за вечер

Минимальные пути для финалистов по официальным инструкциям. Домены, TLS и бэкапы — по ссылкам из каждой карточки.

Mattermost · docker compose

Официальный репозиторий mattermost/docker: клонировать, заполнить .env (домен, версия), поднять с nginx или без. Минимум 2 ГБ RAM на хост.

# по гайду Deploy Mattermost via Docker
git clone https://github.com/mattermost/docker
cd docker && cp env.example .env
# в .env: DOMAIN=chat.example.com, MATTERMOST_IMAGE_TAG
mkdir -p ./volumes/app/mattermost/{config,data,logs,plugins,client/plugins,bleve-indexes}
sudo chown -R 2000:2000 ./volumes/app/mattermost
sudo docker compose -f docker-compose.yml -f docker-compose.nginx.yml up -d

Team Edition — образ mattermost-team-edition; Entry — обычный образ Enterprise без лицензии.

Zulip · один скрипт

Чистый Ubuntu 24.04 или Debian 12 с 2 ГБ RAM. Скрипт сам ставит nginx, PostgreSQL, Redis, RabbitMQ и выпускает сертификат Let's Encrypt.

# по гайду Production installation
cd $(mktemp -d)
curl -fLO https://download.zulip.com/server/zulip-server-latest.tar.gz
tar -xf zulip-server-latest.tar.gz
./zulip-server-*/scripts/setup/install --certbot \
  --email=admin@example.com --hostname=chat.example.com

Мобильные push свыше 10 пользователей — регистрация сервера в push-сервисе Zulip и план Basic.

Element Server Suite Community · k3s + Helm

Шесть шагов из README: DNS, k3s на одной машине, TLS, установка чарта, первый пользователь, проверка. Минимум 2 CPU и 2 ГБ.

# по README ess-helm (Quick setup)
curl -sfL https://get.k3s.io | sh -
# затем: helm upgrade --install ess oci://ghcr.io/element-hq/ess-helm/matrix-stack \
#   -f hostnames.yaml -f tls.yaml --namespace ess --create-namespace
# точные значения и файлы — в README репозитория

Если Kubernetes не хочется — matrix-docker-ansible-deploy ставит тот же стек через Ansible и Docker.

Campfire · одна команда

Для команды, которой нужен просто чат с ботами по HTTP. Один сервер с Docker.

# со страницы once.com/campfire
curl https://get.once.com/campfire | sh

Импорта из Slack нет, начинаете с чистого листа.

Отсеяны и почему

Популярные «альтернативы Slack», которые не проходят по условию self-host или не подходят под рабочее пространство.

Pumble, Zoho Cliq, Ryver — облачные сервисы; официального on-premise предложения не найдено. Zoho предлагает on-prem только для Analytics и Creator.
Chanty, Flock — self-host упоминается лишь в сторонних сравнениях с противоречивыми цифрами; на официальных сайтах подтверждения нет. Не считаем.
Spacebar (ex-Fosscord) — Discord-совместимый сервер, активно развивается (коммиты сентября 2026), но это реплика Discord для сообществ, а не рабочий чат с платформой приложений.
Tinode — Go-сервер мессенджера, релизы в 2026 году есть, но авторы сами называют его beta-quality; это конструктор мессенджера, а не готовая замена Slack.
SimpleX Chat — защищённый мессенджер с self-hosted релеями, но без каналов-рабочих пространств и платформы приложений в смысле Slack.
Mattermost Apps Framework — упомянут отдельно, потому что по нему ещё много статей: объявлен deprecated в v10, перестал работать в v11. Новые интеграции — только плагины, вебхуки и слэш-команды.
