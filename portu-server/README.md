# syferpu.top/portu — карточки португальского и звонки с персонажами

Серверная версия приложения карточек (`flashcards-pt`) на рабочем VPS (`serv_raboch`, Hostinger).

## Что умеет

- **Вход по паролю.** Пароль — это профиль. На сервере хранится только HMAC пароля с секретом `PEPPER`, а не сам пароль. После входа устройство получает httpOnly-куку на 400 дней и пароль больше не спрашивает. Неизвестный пароль — вопрос «создать профиль?». Больше 10 попыток с одного IP за 15 минут не пропускаются.
- **Синхронизация прогресса.** Каждая карточка и каждый день журнала несут метку `t`, слияние идёт по ней (`app/merge.py`, та же логика в `web/portu.js`). Изменения уходят через секунду после ответа, а свежий прогресс подтягивается при возвращении во вкладку. «Обнулить всё» действует на всех устройствах (`resetAt`).
- **Перенос со старой страницы.** `cartoes-pt.html` на GitHub показывает плашку «переехало». Кнопка на ней упаковывает прогресс во фрагмент адреса `#import=…` (на сервер он в запросе не уходит). Страница `/portu` после входа сливает его в профиль.
- **Звонки с ИИ-персонажами.** Встроенные персонажи: Пеппа, Стич, Лунтик, Биа и Каю. Можно добавить своего из фото: Grok на ПК делает мультяшную версию (см. `worker/`). Свои персонажи видны только их владельцу.
  - Распознавание: Whisper. Ответы: `gpt-oss-120b` (оба через Groq, бесплатно).
  - Голос: Microsoft Edge neural (edge-tts), бразильские и русские голоса со сдвигом высоты.
  - Персонаж отвечает на языке вопроса: спросили по-русски — объясняет по-русски и повторяет фразу по-португальски.
  - После звонка: оценка сложности (меняет уровень A1–B2) и разбор с советами по ошибкам. Вся история звонков сохраняется.
- **Офлайн.** Карточки работают без сети (`cartoes-sw.js`); звонкам сеть нужна.

## Устройство

| Что | Где |
|---|---|
| API и статика | `app/` (FastAPI, SQLite в `data/portu.sqlite3`) |
| Клиент звонков и синхронизации | `web/portu.js`, `web/portu.css` → `public/` |
| Сборка `public/index.html` | `../flashcards-pt/build_portu.py` (тот же шаблон, что у GitHub-версии) |
| Встроенные персонажи | `stock/<id>.webp` — полный рост, `_talk` — с открытым ртом, `_av` — портрет |
| Мультяшные персонажи из фото | `worker/grok_worker.py` на ПК anton (Grok CLI по подписке) |

Сервер: `/opt/portu`, контейнер `portu` слушает `127.0.0.1:8095`. Caddy отдаёт `syferpu.top/portu*` без tinyauth и с `X-Robots-Tag: noindex`. Остальной `syferpu.top` закрыт tinyauth, как и раньше.

## Выкладка

```bash
cd flashcards-pt && python build_portu.py        # собрать public/
# упаковать app stock public Dockerfile docker-compose.yml requirements.txt и залить в /opt/portu
ssh serv_raboch 'cd /opt/portu && docker compose up -d --build'
```

Если менялись только `public/` или `stock/`, пересборка не нужна: они смонтированы томами. Картинки слов лежат в `public/cartoes-img` (копия `../cartoes-img`, в git не входит).

## Платный API Grok вместо Groq

На console.x.ai нужен предоплаченный баланс: в подписку SuperGrok он не входит. Цены на 17.04.2026 ([x.ai/news/grok-stt-and-tts-apis](https://x.ai/news/grok-stt-and-tts-apis)): распознавание $0,10 за час, озвучка $15 за 1 млн символов.

Чтобы переключиться, впишите в `/opt/portu/.env` ключ `XAI_API_KEY=…` и строки `LLM_PROVIDER=xai`, `STT_PROVIDER=xai`, затем выполните `docker compose up -d`.

## Обработчик фото (на сервере)

Служба `portu-grok-worker` работает на serv_raboch под пользователем `portugrok` (без sudo). Grok CLI стоит в `/home/portugrok/.grok/bin/grok`, у него свой вход в аккаунт anton, выполненный через `grok login --device-auth`. Раз в 45 секунд служба забирает новые фото через `http://127.0.0.1:8095/portu/api/worker/…`. На каждое фото Grok делает портрет, полный рост и кадр с открытым ртом, всего около 2–5 минут. В промпте полного роста над головой оставляется пустая четверть кадра: там лежат кнопки звонка. Из кадра со ртом вклеивается только область рта.

- лог: `/home/portugrok/portu-work/worker.log`, `journalctl -u portu-grok-worker`;
- если Grok разлогинился: `bash /opt/portu/deploy/login_grok.sh`, затем подтвердить код в браузере;
- удалить профиль вручную: `bash /opt/portu/deploy/drop_user.sh <id>`; в приложении есть кнопка «Удалить профиль целиком».

`worker/grok_worker.py` можно запустить и на ПК, если положить рядом `worker/.env`.
