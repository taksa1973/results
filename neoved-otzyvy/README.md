# «Отзывы клиентов» — галерея скриншотов для neoved.io

Галерея раздаётся с сервера neoved: `https://hooks.neoved.io/amo/neoved-otzyvy/` (воркер `neoved-otzyvy` в amo-server).

Тест (копия главной, закрыта от индексации): https://taksa1973.github.io/results/neoved-otzyvy-test.html#otzyvy

## Как поставить на сайт — одна строка

В Tilda на главной после раздела «На чем основано доверие клиентов?» добавить блок T123 «HTML-код» и вставить:

```html
<script src="https://hooks.neoved.io/amo/neoved-otzyvy/otzyvy.js" defer></script>
```

Галерея с заголовком «Отзывы клиентов» появится на месте этой строки. Своих отступов сверху и снизу у неё нет: между разделами нужен обычный блок-отступ сайта.

## Правки

1. Править `block.html` (стили, разметка, скрипт) или картинки в `img/neoved-otzyvy/`.
2. `SSH_PASSPHRASE=… python neoved-otzyvy/deploy.py` — соберёт `otzyvy.js`, зальёт на сервер, пересоберёт контейнер (все воркеры перезапускаются на несколько секунд) и проверит, что всё поднялось.

Строку на сайте менять не нужно. Скрипт кэшируется на 10 минут, картинки на сутки: если заменить картинку, в `block.html` поднять `?v=N` у её адресов.

## Файлы

- `block.html` — исходник галереи.
- `build-embed.py` — собирает из него `otzyvy.js`.
- `server/worker.js` — воркер раздачи: `/otzyvy.js`, `/img/otzyv-N-480|720|1080.webp`, `/health`.
- `deploy.py` — выкладка на сервер neoved.
- `build-test.py` — тестовая страница: копия главной без счётчиков, с `noindex`, в «HTML-коде» та же одна строка.
