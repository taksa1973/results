# «Отзывы клиентов» — галерея скриншотов для neoved.io

Тестовая страница — копия главной neoved.io с разделом «Отзывы клиентов» после «На чем основано доверие клиентов?» (закрыта от индексации):
https://taksa1973.github.io/results/neoved-otzyvy-test.html#otzyvy

Код для вставки (открывается текстом, копировать целиком):
https://raw.githubusercontent.com/taksa1973/results/master/neoved-otzyvy/block.html

## Как добавить на главную

1. В Tilda на главной нажать «+» после раздела «На чем основано доверие клиентов?» (под его вкладками), перед отступом над «Наши партнеры».
2. Поставить такой же блок-отступ, как между разделами сайта (120 px, на телефоне 60).
3. Под ним — блок T123 «HTML-код» с `block.html` целиком.

В коде уже есть заголовок «Отзывы клиентов» в стиле заголовков сайта и галерея. Своих отступов сверху и снизу у блока нет.

## Картинки

Скриншоты ничем не замазаны. Чтобы грузились быстро, в `img/neoved-otzyvy/` лежат копии в WebP: `-480` и `-720` для ленты (45–110 КБ), `-1080` — полный размер 1080×2424 для lightbox (150–220 КБ). Превью грузятся сразу с низким приоритетом, полные версии — в фоне, когда галерея рядом, и при наведении.

Картинки грузятся с GitHub Pages. Если перенести их в другое место, в `block.html` заменить префикс `https://taksa1973.github.io/results/img/neoved-otzyvy/`.

## Пересборка тестовой страницы

`python neoved-otzyvy/build-test.py` из корня репозитория: свежая копия главной без счётчиков, с `noindex` и разделом на своём месте.
