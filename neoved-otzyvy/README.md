# «Отзывы без редакции» — галерея для neoved.io/keysy-i-otzyvy

Тестовая страница (копия страницы «Кейсы и отзывы» с галереей на месте «+», закрыта от индексации):
https://taksa1973.github.io/results/neoved-otzyvy-test.html#otzyvy

Код для вставки (открывается текстом, копировать целиком):
https://raw.githubusercontent.com/taksa1973/results/master/neoved-otzyvy/block.html

## Как добавить на сайт

1. В Tilda на странице «Кейсы и отзывы» нажать «+» между отступом под заголовком «Отзывы без редакции» и подписью «Личные данные скрываем…».
2. Выбрать блок T123 «HTML-код» и вставить в него `block.html` целиком.

У блока нет своих отступов сверху и снизу.

## Картинки

Скриншоты ничем не замазаны. Чтобы грузились быстро, в `img/neoved-otzyvy/` лежат копии в WebP:
- `-480` и `-720` — для ленты, браузер берёт подходящую под экран (45–110 КБ вместо 580–850 КБ у PNG);
- `-1080` — полный размер 1080×2424 для lightbox (150–220 КБ).

Превью начинают грузиться примерно за полтора экрана до галереи, полные версии подтягиваются в фоне, когда галерея на экране, и при наведении на карточку.

Картинки грузятся с GitHub Pages. Если перенести их в другое место, в `block.html` заменить префикс `https://taksa1973.github.io/results/img/neoved-otzyvy/`.

## Пересборка тестовой страницы

`python neoved-otzyvy/build-test.py` из корня репозитория: свежая копия боевой страницы без счётчиков, с `noindex` и блоком на месте «+».
