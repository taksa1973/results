## Как добавить на сайт

1. В Tilda на странице «Кейсы и отзывы» нажать «+» между отступом под заголовком «Отзывы без редакции» и подписью «Личные данные скрываем…».
2. Выбрать блок T123 «HTML-код» и вставить в него `block.html` целиком.

У блока нет своих отступов сверху и снизу. Скриншоты — оригиналы, лежат в `img/neoved-otzyvy/` и грузятся с GitHub Pages. Если перенести их в другое место, в `block.html` заменить префикс `https://taksa1973.github.io/results/img/neoved-otzyvy/` на новый адрес.
