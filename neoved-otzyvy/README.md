# «Отзывы клиентов» — галерея скриншотов для neoved.io

Тест (копия главной, закрыта от индексации): https://taksa1973.github.io/results/neoved-otzyvy-test.html#otzyvy

## Как поставить на сайт — одна строка

В Tilda на главной после раздела «На чем основано доверие клиентов?» добавить блок T123 «HTML-код» и вставить:

```html
<script src="https://taksa1973.github.io/results/neoved-otzyvy/otzyvy.js" defer></script>
```

Галерея с заголовком «Отзывы клиентов» появится на месте этой строки. Своих отступов сверху и снизу у неё нет: между разделами нужен обычный блок-отступ сайта (120 px, на телефоне 60).

Правки в галерее подтягиваются сами: строку на сайте менять не нужно.

## Файлы

- `block.html` — исходник: стили, разметка, скрипт. Править здесь.
- `otzyvy.js` — то, что подключает строка; собирается из `block.html`: `python neoved-otzyvy/build-embed.py`.
- `build-test.py` — пересобирает `otzyvy.js` и тестовую страницу (копия главной без счётчиков, с `noindex`, в «HTML-коде» та же одна строка).
- `img/neoved-otzyvy/` — скриншоты: `-480` и `-720` для ленты, `-1080` для увеличенного просмотра.
