# Карта на странице «Контакты» neoved.io

Чёрно-белая Яндекс Карта организации в блоке контактов `https://neoved.io/kontakty` по ТЗ
[«Контакты (новый)»](https://neoved.notion.site/3fad7b0c587c8027978bea1b42305d13): слева карточка
контактов, справа карта; на планшете и телефоне карта под карточкой.

Раздаётся с сервера neoved: `https://hooks.neoved.io/amo/neoved-kontakty/kontakty.js`
(воркер `neoved-kontakty` в amo-server).

Тест (копия страницы контактов, закрыта от индексации): https://taksa1973.github.io/results/neoved-kontakty-test.html

## Как поставить на сайт — одна строка

В Tilda на странице `/kontakty` добавить блок T123 «HTML-код» (место на странице не важно) и вставить:

```html
<script src="https://hooks.neoved.io/amo/neoved-kontakty/kontakty.js" defer></script>
```

Карта сама встаёт в пустой прямоугольник, который дизайнер оставил в Zero Block контактов
(`rec4713202201`, элемент `1792177730811000001`): 570×535 справа на десктопе, во всю ширину под
карточкой на телефоне; скругление и рамка остаются его. Если прямоугольник из блока удалить,
карта встанет на место строки как отдельная карточка 570×535.

Тот же код можно вставить и без сервера: содержимое `block.html` целиком — в HTML-элемент Zero Block
на месте прямоугольника или в блок T123.

## Что внутри

- **С 26.11.2026 карта на JavaScript API 2.1 Яндекс Карт, а не виджетом-iframe.** Причина — видео anton:
  у виджета внизу рекламный блок Яндекса, реклама меняется примерно раз в 30 с, и в Chrome на Mac
  виджет при этом гас целиком и загружался заново («скачет»). Рекламу в виджете не отключить: она есть
  во всех режимах (`map-widget/v1/org/…`, `?pt=`, `?mode=search&oid=`, `?poi[uri]=` — проверено),
  а закрывать её, копирайт, логотип или кнопку «Открыть в Картах» запрещено условиями Яндекса. В карте на
  JS API рекламного блока нет, и перезагружаться нечему: карта — наш `div`.
- Подложка серая (`grayscale` только у слоя `ground`), метка красная #ee0000, как кнопки сайта. Адрес,
  который был в карточке организации виджета, — в своей карточке поверх карты: «Москва, Большая Бронная
  улица, 23, стр. 1», метро Тверская, Пушкинская, Чеховская, ссылка «Открыть на Яндекс Картах» на карточку
  организации (отзывы, часы работы). Кнопка Яндекса «Как добраться», копирайт и логотип не перекрываются.
  Точка — координаты организации в Яндексе: 55.763371, 37.601412.
- **Ключ API** — константа `KEY` в `block.html`. Бесплатный: кабинет разработчика
  https://developer.tech.yandex.ru/services → «Подключить API» (JavaScript API), в ограничениях ключа —
  HTTP Referer `neoved.io` (начинают действовать через 15 минут). Условия бесплатного использования:
  https://yandex.ru/dev/commercial/doc/ru/ (сайт открыт всем), юридический текст — https://yandex.ru/legal/maps_api/
  (редакция от 01.09.2026). Отключение возможной рекламы в JS API — тариф «Базовый (без рекламы)»,
  2 000 ₽ в месяц / 20 000 ₽ в год, сейчас не нужен: рекламного блока в карте JS API нет.
- **Пока `KEY` пустой** или API не загрузился (ошибка, 15 с без карты), на месте карты прежний виджет из ТЗ
  (`yandex.ru/map-widget/v1/org/neoved_/175160083981`, z=17), чёрно-белый через `filter: grayscale(1)`
  на iframe, с рекламой. Домен `yandex.ru`, а не `yandex.com` из ТЗ: у `.com` интерфейс английский.
- API грузится после `load` страницы и когда блок в 300 px от экрана, в своё пространство имён
  (`ns=nvkYmaps`), чтобы не столкнуться с другой копией API на странице.
- Колесо мыши над картой не масштабирует её, пока по карте не кликнули (при наведении подсказка
  «Нажмите, чтобы управлять картой»); курсор ушёл — карта снова «спит». Иначе страница не
  прокручивалась бы, когда курсор стоит над правой половиной первого экрана. На телефоне карта
  включается тапом, пролистывание пальцем над ней страницу не блокирует; ушла с экрана — выключается.
- Карта растянута по плейсхолдеру абсолютным позиционированием, а не `height:100%`: на телефоне
  Tilda верстает плейсхолдер таблицей (`.tn-elem` — table, `.tn-atom` — table-cell), и в Safari блок
  с `height:100%` внутри ячейки получал нулевую высоту — карты не было видно (20.10.2026). Если
  высоты всё равно нет, скрипт ставит её в пикселях по плейсхолдеру и держит при ресайзе.
- Карта JS API проявляется, когда догрузились тайлы. Запасной виджет — через 2 с после своей загрузки:
  сразу после `load` он ещё около секунды доводит карту до точки, и это выглядело как «прыжок» в начале.
- Кнопки «Zoom», «Google Meet» и (с 25.11.2026) «Zoho Meeting» в карточке контактов (группы
  `.cardzm`) без ссылки на SimplyMeet, поэтому скрипт помечает их
  `data-neoved-meeting="zoom|meet|zoho"` по тексту — попап записи
  (`amo-booking-worker/widget.js`) открывается по ним сразу с выбранным форматом, с клавиатуры —
  Enter или пробел. В «Zoho Meeting» есть «meet» — Google Meet узнаётся по «google» или «meet»
  без «ing». Кнопке со ссылкой `#neoved-meeting-zoho` пометка не нужна.
- Наведение на кнопки видеовстреч: 25.11.2026 сделали красным, как у мессенджеров, но 26.11.2026 anton попросил
  вернуть как было — текст не меняется, значок серый и при наведении на кнопку (на значок или название) загорается
  своими цветами. Это CSS дизайнера в Tilda (`.cardzm` → `grayscale`, `:hover` → `filter:none`); kontakty.js
  повторяет то же правило на случай, если его там не будет. Страница контактов переехала на `/o-nas/kontakty`
  (со старого адреса 301), блок тот же — `rec4713202201`. Кнопка «Записаться в Zoom / Meet» ниже по странице по-прежнему ведёт на
  SimplyMeet и перехватывается попапом по ссылке. В Tilda менять ничего не нужно.

## Правки

1. Править `block.html` (стили, разметка, скрипт).
2. `SSH_PASSPHRASE=… python neoved-kontakty/deploy.py` — соберёт `kontakty.js`, зальёт на сервер,
   пересоберёт образ (все воркеры перезапускаются на несколько секунд) и проверит, что всё поднялось.

Строку на сайте менять не нужно, скрипт кэшируется на 10 минут.

## Файлы

- `block.html` — исходник карты.
- `build-embed.py` — собирает из него `kontakty.js`.
- `server/worker.js` — воркер раздачи: `/kontakty.js`, `/health`.
- `deploy.py` — выкладка на сервер neoved.
- `build-test.py` — тестовая страница: копия `/kontakty` без счётчиков, с `noindex`;
  `--github` — до выкладки (карта и новый `widget.js` с GitHub Pages), `--local` — проверка на своей машине.
