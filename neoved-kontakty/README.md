# Карта на странице «Контакты» neoved.io

Чёрно-белая Яндекс Карта организации в блоке контактов `https://neoved.io/kontakty` по ТЗ
[«Контакты (новый)»](https://neoved.notion.site/3fad7b0c587c8027978bea1b42305d13): слева карточка
контактов, справа карта; на планшете и телефоне карта под карточкой.

Раздаётся с сервера neoved: `https://hooks.neoved.io/amo/neoved-kontakty/kontakty.js`
(воркер `neoved-kontakty` в amo-server).

Тест (копия страницы контактов, закрыта от индексации): https://taksa1973.github.io/results/neoved-kontakty-test.html

## Как поставить на сайт — одна строка

В Tilda на странице `/kontakty` добавить блок T123 «HTML-код» (место на странице не важно) и вставить:

```html
<script src="https://hooks.neoved.io/amo/neoved-kontakty/kontakty.js" defer></script>
```

Карта сама встаёт в пустой прямоугольник, который дизайнер оставил в Zero Block контактов
(`rec4713202201`, элемент `1792177730811000001`): 570×535 справа на десктопе, во всю ширину под
карточкой на телефоне; скругление и рамка остаются его. Если прямоугольник из блока удалить,
карта встанет на место строки как отдельная карточка 570×535.

Тот же код можно вставить и без сервера: содержимое `block.html` целиком — в HTML-элемент Zero Block
на месте прямоугольника или в блок T123.

## Что внутри

- Виджет из ТЗ (`yandex.ru/map-widget/v1/org/neoved_/175160083981`, точка 37.601412, 55.763372, z=17),
  чёрно-белый через `filter: grayscale(1)` на iframe. Домен `yandex.ru`, а не `yandex.com` из ТЗ:
  у `.com` интерфейс виджета английский.
- Колесо мыши над картой не масштабирует её, пока по карте не кликнули (при наведении подсказка
  «Нажмите, чтобы управлять картой»); курсор ушёл — карта снова «спит». Иначе страница не
  прокручивалась бы, когда курсор стоит над правой половиной первого экрана. На телефоне карта
  включается тапом, пролистывание пальцем над ней страницу не блокирует; ушла с экрана — выключается.
- Кнопки «Zoom» и «Google Meet» в карточке контактов ведут на SimplyMeet — их перехватывает попап
  записи (`amo-booking-worker/widget.js`) и с 19.10.2026 открывается сразу с выбранным форматом
  (по тексту кнопки). В Tilda менять ничего не нужно.

## Правки

1. Править `block.html` (стили, разметка, скрипт).
2. `SSH_PASSPHRASE=… python neoved-kontakty/deploy.py` — соберёт `kontakty.js`, зальёт на сервер,
   пересоберёт образ (все воркеры перезапускаются на несколько секунд) и проверит, что всё поднялось.

Строку на сайте менять не нужно, скрипт кэшируется на 10 минут.

## Файлы

- `block.html` — исходник карты.
- `build-embed.py` — собирает из него `kontakty.js`.
- `server/worker.js` — воркер раздачи: `/kontakty.js`, `/health`.
- `deploy.py` — выкладка на сервер neoved.
- `build-test.py` — тестовая страница: копия `/kontakty` без счётчиков, с `noindex`;
  `--github` — до выкладки (карта и новый `widget.js` с GitHub Pages), `--local` — проверка на своей машине.
