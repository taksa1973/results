2 Telegram + 1 WhatsApp на «Базовом» Wappi: да, через наш канал чатов

Готовая интеграция с amoCRM у Wappi есть только в тарифе «Полный». Но в «Базовом» есть API нужного мессенджера, а у neoved в amoCRM уже подключён свой канал чатов: через него идут чат на сайте, Telegram-канал и почта. Новые три номера встают туда же, а связку пишем сами. Переписка будет в карточке, менеджер отвечает из amoCRM.

1Короткий ответ

Да, сможем

  • В «Базовом» есть Telegram API в карточке Telegram и WhatsApp API в карточке WhatsApp. На сайте Wappi это видно, если переключить мессенджер над тарифами.
  • Через API приходят входящие и ответы, отправленные с телефона (отдельный тип уведомления outgoing_message_phone), а отправлять можно текст и файлы.
  • В amoCRM канал чатов neoved подключён с сентября. Ответы менеджеров из карточки он уже раздаёт по трём направлениям: сайт, Telegram-канал, почта. Добавляются ещё три номера.
  • Ответ с телефона amoCRM позволяет записать в карточку от имени менеджера, поэтому контроль SLA его увидит.

Чем платим за экономию

  • Работа: новый воркер на нашем сервере, по образцу tg-amo и чата на сайте. Оценка: 2–3 дня на код и тесты плюс день проверки на живых номерах. Это прикидка по объёму похожих воркеров, а не замер.
  • Нет «Написать первым» из карточки: наш канал зарегистрирован без этой функции. Первое сообщение можно отправить с телефона (оно попадёт в карточку) или командой в ленте сделки.
  • Нет групповых чатов, рассылок из amoCRM и Salesbot: всё это в «Полном» есть.
  • Чиним сами: если сломается, разбираемся мы, а не поддержка Wappi.
Рекомендация. Пишем воркер, проверяем его на бесплатных 5 днях, затем оплачиваем «Базовый» на 1 месяц (3 × 700 = 2 100 ₽). Если месяц пройдёт без сбоев, переходим на год по 550 ₽. Страховка обойдётся в 450 ₽: столько первый месяц стоит дороже годовой ставки. Если тест провалится, берём «Полный» и своё не пишем.

4Что уже есть и что дописать

Уже работает

  • Канал чатов amoCRM с подписанными запросами. Код подключения лежит в neoved-chat-worker/amojo.js.
  • Раздача ответов менеджеров по направлениям: сайт, Telegram-канал, почта.
  • Порядок, проверенный на ошибках: сначала контакт и сделка, потом чат и привязка, потом сообщения. Иначе amoCRM заводит своё «Неразобранное».
  • Источники бесед для триггеров цифровой воронки, чтобы теги не путались.
  • Сервер с воркерами и журналом каждого запроса.

Дописать

  • Приём уведомлений Wappi от трёх профилей с проверкой ключа.
  • Поиск контакта: по телефону для WhatsApp, по Telegram ID или нику для Telegram.
  • Отправку ответа в нужный профиль Wappi.
  • Файлы в обе стороны: фото, документы, голосовые. amoCRM принимает файл только по ссылке, значит его временно раздаёт наш сервер.
  • Запись ответов с телефона от имени менеджера. Нужна таблица «номер → менеджер».
  • Статусы «доставлено» и «прочитано».
  • Оповещение, если номер разлогинился (authorization_status).
  • Три новых источника бесед, правку триггеров тегов telegram_sales и whatsapp_sales, подпись нового канала в контроле SLA.
  • «Источник» по метке «Моя заявка: …» из первого сообщения, как сейчас делает amo-source.

6Риски и что проверить на тесте

Уведомления на «Базовом»

В описании тарифов уведомления (вебхуки) не упомянуты. В документации API они описаны как часть API без оговорок про тариф. Это первое, что проверяем в бесплатные дни.

Ответ из amoCRM уходит один раз

По документации amoCRM уведомление об ответе менеджера при ошибке не повторяется. Поэтому воркер пишет каждый ответ в журнал и сам повторяет отправку в Wappi, если та не прошла.

Блокировки

Wappi сам предупреждает: за спам Telegram может забанить аккаунт, а безлимит Wappi не отменяет ограничений Telegram. Для WhatsApp — блокировка номера за спам и неразрешённую автоматизацию. Для обычной переписки с клиентами риск такой же, как сейчас.

Две переписки у старых клиентов

Сейчас Telegram neoved идёт в amoCRM через готовую интеграцию Wappi. После перехода старые беседы останутся в карточках историей, а новые сообщения пойдут отдельной беседой нашего канала.

Файлы

В анкете нашего канала отмечено «хранение файлов: нет». На тесте проверяем, как открываются картинки и документы клиентов. Возможно, их придётся хранить у себя дольше.

Соседние воркеры

amo-meet, amo-phone и контроль SLA сейчас рассчитаны на сделки и беседы Wappi. На тесте проверяем, что новые сделки они видят так же.

7План

Воркер

Пишем и прогоняем тесты на заглушках. Денег на этом шаге не тратим.

Тест 5 дней

В Wappi включаем бесплатный период на «Базовом», подключаем один Telegram. Проверяем входящие, ответ из карточки, ответ с телефона, файлы и SLA.

Ещё два номера

На тесте подключаем второй Telegram и WhatsApp. Бесплатный период даётся «для каждого мессенджера».

Оплата

Сначала 1 месяц за 2 100 ₽, после месяца без сбоев — год за 19 800 ₽. Текущую интеграцию до этого не отключаем.

Если тест не пройдёт (нет уведомлений на «Базовом», ответы с телефона не доходят): берём «Полный» на год за 48 600 ₽ и пользуемся готовой интеграцией Wappi.
